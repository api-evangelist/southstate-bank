# SouthState Bank

> SouthState Bank serves consumer, mortgage, small business, commercial, wealth, and retirement-plan audiences. The site includes product pages, service overviews, application and contact paths, educational hubs, and branch or advisor discovery.

This `llms.txt` file is intentionally curated from the public sitemap to favor stable, high-signal pages over one-off articles, campaign pages, staff pages, and utility-only tools.

Use this file as a routing guide:
- Start with **Core Site Sections** for audience-level navigation.
- Use the product sections when the user asks about a specific account type, loan type, or banking need.
- Use **Support, Policies, and Service Information** for servicing, fees, privacy, and branch lookup.
- Use **Optional** hubs when the request is educational or research-oriented rather than transactional.
